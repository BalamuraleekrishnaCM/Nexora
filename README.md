## Install for development
In Unity Package Manager choose Add package from git URL and use `https://github.com/BalamuraleekrishnaCM/Nexora.git?path=/Packages/com.nexora.xrcore#feature/nexora-delivery-20261127` (replace package name as needed). Target Unity 2022.3 LTS and Unity 6; compatibility not yet tested. Use a disposable project first.
