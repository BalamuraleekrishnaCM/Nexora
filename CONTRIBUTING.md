# Contributing to Nexora

Open an issue describing the bug or proposal before large changes. Work in a feature branch and submit a PR. Keep changes scoped to one package when possible. Include tests for behavior changes, sample updates for user-visible features, and changelog entries for releases.

## Review checklist
- [ ] No unrelated package changes
- [ ] No hard-coded project paths or machine-specific settings
- [ ] No UnityEditor references in runtime assemblies
- [ ] EditMode tests pass in supported Unity versions
- [ ] Samples import without missing scripts
- [ ] README and package documentation reflect behavior
- [ ] No secrets, binary SDKs or proprietary assets committed

Maintainer approval is required before merge and publication.
